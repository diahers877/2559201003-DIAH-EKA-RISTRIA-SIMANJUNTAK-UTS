## 2. Deskripsi Website

Personal Portfolio Website merupakan website portofolio pribadi yang dibuat untuk memperkenalkan profil, latar belakang pendidikan, kemampuan, serta proyek yang telah dikerjakan.

Website ini dirancang dengan tampilan modern dan profesional menggunakan kombinasi warna navy blue, dusty blue, dan putih. Tujuannya adalah menampilkan informasi pribadi dan hasil karya dalam bentuk website yang menarik, mudah dipahami, serta responsif.

## 3. Halaman Website

Website ini memiliki empat halaman utama:

1. **Home (Beranda)**  
   Menampilkan perkenalan singkat, tagline, foto profil, tombol navigasi, ringkasan informasi, serta teknologi yang sedang dipelajari.

2. **About (Tentang)**  
   Berisi profil pribadi, latar belakang pendidikan, serta ketertarikan dalam bidang web development, UI/UX design, dan problem solving.

3. **Projects (Proyek)**  
   Menampilkan enam proyek yang berkaitan dengan pengembangan website, pemrograman, pengelolaan database, dan desain antarmuka.

4. **Contact (Kontak)**  
   Menyediakan informasi kontak dan formulir pesan yang dilengkapi validasi HTML5.

## 4. Teknologi yang Digunakan

- **HTML5:** Membuat struktur dan isi halaman website.
- **CSS3:** Mengatur tampilan, warna, tata letak, animasi, dan responsivitas website.

## 9. Kendala dan Cara Mengatasinya

Beberapa kendala yang ditemukan selama proses pembuatan website:

1. **Foto profil tidak muncul.**  
   Cara mengatasi: Memeriksa kembali nama file dan lokasi gambar agar sesuai dengan alamat yang ditulis pada HTML.

2. **Tampilan elemen kurang rapi.**  
   Cara mengatasi: Memperbaiki pengaturan CSS, seperti ukuran, posisi, jarak, dan tata letak elemen.

3. **Tampilan website pada ukuran layar berbeda.**  
   Cara mengatasi: Menggunakan media query agar tata letak dapat menyesuaikan ukuran layar perangkat.

## 10. Cara Menjalankan Website

1. Buka folder proyek menggunakan Visual Studio Code.
2. Pastikan seluruh file HTML, CSS, dan gambar berada pada folder yang sesuai.
3. Buka file `index.html` menggunakan browser atau ekstensi Live Server.
4. Gunakan menu navigasi untuk mengakses halaman lainnya.
